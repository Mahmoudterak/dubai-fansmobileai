نظرة عامة على الواجهة

واجهة شركاء Dubai Fans AI تتيح لسيرفرك طلب تصاميم إعلانية وفيديوهات وصفحات هبوط ومواقع ونصوص عربية، واستلام النتيجة الجاهزة. كل طلب يصبح "مهمة" تعمل في الخلفية.

الواجهة للشركاء فقط. للحصول على مفتاح تواصل معنا عبر واتساب أو على info@mtuaefans.com. احفظ مفتاحك في سيرفرك فقط، ولا تضعه في المتصفح أو تطبيق الجوال.

عنوان الأساس

كل نقاط النهاية تُكتب بعد هذا العنوان. الطلبات والردود بصيغة JSON عبر HTTPS.

url
https://ai.mtuaefans.com/api/partner/v1

المصادقة

أرسل مفتاحك في ترويسة Authorization بصيغة Bearer:

http
Authorization: Bearer YOUR_API_KEY

إذا كان المفتاح ناقصاً أو خاطئاً يعود الرد 401 auth.

إرسال الطلبات

مثال: طلب تصميم إعلاني. يعود الرد 202 مع معرّف مهمة يمكنك استعلامه أو استلامه عبر webhook.

bash
curl -X POST https://ai.mtuaefans.com/api/partner/v1/designs \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Summer sale, 30% off all abayas","size":"story","brand":{"name":"Example Shop","primary":"#6D4AFF"},"callback_url":"https://example.com/webhooks/dfai"}'
json
{ "id": "job_…", "status": "queued", "status_url": "https://ai.mtuaefans.com/api/partner/v1/jobs/job_…" }

المهام

لكل مهمة حالة من: queued أو running أو done أو failed. اقرأ المهمة عبر GET /jobs/{id}. عند done يحتوي result على الناتج، وعند failed يشرح error السبب.

bash
curl https://ai.mtuaefans.com/api/partner/v1/jobs/JOB_ID \
  -H "Authorization: Bearer YOUR_API_KEY"

POST/designs

الحقول: prompt أو product_image (واحد منهما على الأقل)، وsize (portrait أو square أو story أو wide)، وlayouts (مصفوفة أو recommended)، وbrand وcopy وcallback_url وcustomer_id اختيارية. النتيجة تسرد التصاميم مع رابط لكل تخطيط.

POST/videos

الحقول: prompt أو product_image أو design_job_id، وduration (من 6 إلى 15 ثانية). الناتج 1080 × 1920 بدون صوت. إذا أرسلت prompt أو صورة منتج فقط، يُنشأ تصميم أولاً.

POST/landing-pages

الحقل: prompt مطلوب، ويمكن إضافة brand. النتيجة تحتوي رابطاً منشوراً ومحتوى HTML للصفحة.

POST/websites

الحقل: prompt مطلوب، ويمكن إضافة brand. النتيجة تحتوي رابطاً منشوراً وقائمة بالصفحات، ولكل صفحة رابطها.

POST/text

الحقول: prompt مطلوب، وpurpose: post (الافتراضي) أو ad أو whatsapp. النتيجة تحتوي النص العربي.

الصور والعلامة التجارية

  • product_image يقبل رابط صورة https أو data URL بصيغة base64 (PNG أو JPEG أو WebP أو GIF). الحد الأقصى 8 ميجابايت.
  • brand يقبل name وcategory وdescription وaudience وwhatsapp وwebsite وinstagram وprimary وaccent (ألوان hex مثل #6D4AFF)، وشعار اختياري.

Webhooks

إذا أرسلت callback_url (يجب أن يكون https)، نرسل المهمة إليه عند تغيّر حالتها. كل طلب فيه ترويستان: X-DFAI-Event (مثل job.done) وX-DFAI-Signature وهي sha256= متبوعة بقيمة HMAC-SHA256 للنص الخام باستخدام مفتاحك. تحقق من التوقيع قبل الوثوق بالمحتوى. نعيد المحاولة حتى أربع مرات.

javascript
const expected = 'sha256=' + crypto.createHmac('sha256', API_KEY).update(rawBody).digest('hex');
if (req.headers['x-dfai-signature'] !== expected) return res.status(401).end();

الحدود والاستخدام

لكل شريك حد يومي لعدد المهام. تحقق من الاستهلاك عبر GET /usage. عند الوصول إلى الحد تعود الطلبات الجديدة 429 quota. تُعالَج المهام عدة مرات في نفس الوقت، وتتسع قائمة الانتظار لـ 50 مهمة؛ وبعدها يعود الرد 503 busy، فأعد المحاولة بعد قليل.
