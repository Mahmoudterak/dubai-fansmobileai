سياسة الاستخدام المقبول

آخر تحديث: 2 نوفمبر 2026

توضّح هذه السياسة الاستخدامات المحظورة لخدمة Dubai Fans AI، وهي جزء من شروط الخدمة.

يُحظر استخدام الخدمة في:

  • أي محتوى أو نشاط يخالف قوانين دولة الإمارات العربية المتحدة أو قوانين بلدك.
  • الاحتيال والتصيّد: صفحات أو رسائل تنتحل صفة جهات حقيقية (بنوك، جهات حكومية، شركات) أو تجمع بيانات الدفع أو الدخول بطرق مضللة.
  • الإعلانات المضللة: الادعاءات الصحية أو المالية الكاذبة، أو التقييمات والشهادات المزيفة المقدَّمة على أنها حقيقية، أو الأسعار والعروض الوهمية.
  • انتحال شخصية أفراد أو جهات حقيقية، أو إنتاج صور ومقاطع مزيفة لأشخاص حقيقيين دون موافقتهم.
  • نسخ شعارات أو علامات تجارية أو أعمال محمية مملوكة للغير، أو انتهاك حقوق الملكية الفكرية.
  • الرسائل المزعجة والرسائل الجماعية لأشخاص لم يوافقوا على استلامها.
  • التحرش، أو خطاب الكراهية، أو التحريض على العنف، أو التمييز.
  • أي محتوى جنسي يتعلق بالقاصرين بأي شكل، أو المحتوى الجنسي الصريح عموماً.
  • إنشاء برمجيات ضارة أو اختراق الأنظمة، أو محاولة تجاوز حماية الخدمة أو حدودها.
  • ربط أو رفع بيانات أو متاجر أو حسابات لا تملكها أو غير مصرّح لك بها، أو جمع بيانات الآخرين دون وجه حق.
  • مخالفة سياسات المنصات التي تنشر عليها (مثل سياسات إعلانات Meta وTikTok وGoogle).

الإجراءات

في حال مخالفة هذه السياسة، يحق لنا إزالة المحتوى أو تعليق الحساب مؤقتاً أو إيقافه نهائياً، ودون استرداد للاشتراك في الحالات الجسيمة، وقد نُبلغ الجهات المختصة إذا اقتضى القانون ذلك.
