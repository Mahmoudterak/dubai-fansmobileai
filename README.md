# Dubai Fans AI

منصة الذكاء الاصطناعي لـ Dubai Fans: واجهة دردشة للمستخدمين، وواجهة مساعد، ومركز أدوات (صوت العلامة، تقييم الجمهور، من صورة لكود، باحث العملاء، المستشار، قارن بالمنافس، المهام)، ولوحة إدارة للمسؤولين.

## المكونات

- `api/app/`: خادم Node.js (الإصدار 24) يعمل بقاعدة بيانات SQLite عبر `node:sqlite`. يضم المحادثات (`chats.js`)، ومهام الخلفية (`bgtasks.js`)، والتخزين على Cloudflare R2 (`r2.js`)، وأدوات الذكاء الاصطناعي (`ai-tools/`).
- `site/`: واجهة المستخدم الثابتة، وتضم صفحات الخصوصية والشروط والمساعدة، ومركز الأدوات في `site/ai-tools/`.
- `site/admin.html` و`site/admin.js`: لوحة الإدارة القديمة. اللوحة الحية منفصلة وتُدار كملفات ثابتة مستقلة.
- `install.sh`: سكربت النشر على السيرفر. يأخذ نسخة احتياطية من قاعدة البيانات، وينسخ الـAPI والموقع، ويعيد تشغيل الحاوية، ثم يشغّل اختبارات الدخان.

## الإعدادات

تُقرأ من متغيرات البيئة. لا تضع القيم الحقيقية في المستودع.

| المتغير | الوظيفة |
|---|---|
| `DATA_DIR` | مجلد البيانات (قاعدة البيانات والصور) |
| `TZ_OFFSET_MIN` | فرق التوقيت عن UTC بالدقائق (الإمارات: 240) |
| `R2_ENDPOINT` و`R2_BUCKET` و`R2_ACCESS_KEY_ID` و`R2_SECRET_ACCESS_KEY` | التخزين على R2، وإن لم تُضبط يبقى التخزين محلياً فقط |

## التشغيل المحلي

يحتاج Node.js 24 أو أحدث. الكود الحالي مكتوب بـCommonJS بدون تبعيات خارجية للـAPI.

```bash
node --check api/app/server.js
```

## النشر

```bash
bash install.sh
```

يتطلب السكربت أن يكون مجلد المصدر على السيرفر، وينشر إلى `/opt/dfai`.

## الاختبارات

- اختبارات الدخان (18 اختباراً على سطح المكتب والجوال) تعمل بعد كل نشر، وتتحقق من فتح الصفحات الرئيسية وأن واجهات الإدارة تتطلب تسجيل الدخول.
- اختبارات HTTP لواجهة المحادثات (`chat-http-test`) واختبارات مزامنة المحادثات (`chat-sync-test`) موجودة في مجلد الاختبار المحلي، وليست جزءاً من المستودع.
